# Encore – Ticket 1: Original Generated Test Cases

Generated by exploratory testing of the Encore app (encore-release.apk) on Samsung Galaxy S23.
Total: 29 test cases (T001–T029), all status: not_automated.

---

## Guest Entry & Landing

### T001 — Guest entry via Continue as Guest
**Description:** Verify that tapping 'Continue as Guest' on the landing screen navigates directly to the event list without requiring any sign-in or form fields.
**Priority:** High | **Type:** Functional

**Steps:**
1. Launch the Encore app
   - *Expected:* Landing screen is displayed with 'Encore' title, tagline 'Find a seat. See a show.', and 'Continue as Guest' button
2. Tap 'Continue as Guest'
   - *Expected:* App navigates to the Events list screen showing event cards and category filter chips

**Precondition:** App is freshly installed or session is cleared

### 🐛 Potential Bug — T014
During exploration, entering "INVALID123" and tapping Apply produced **no visible inline error message** in the page source. The PRD states: *"An invalid code shows an inline error and does not block checkout."* No error element (`discount-error`, `discount-invalid-label`, or similar) appeared in the accessibility tree. This should be investigated.
